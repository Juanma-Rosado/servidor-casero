23 Nov 2026 · Class assignment, 1st year

Windows 11 and Linux Mint on the same machine

The task was to install two operating systems in one VirtualBox virtual machine and choose which one to start. Windows 11 needs TPM and Secure Boot, and with Secure Boot the Linux Guest Additions don't load unless they are signed, so I had to sign them too.

  • Windows 11 Pro 24H2 with TPM 2.0 and Secure Boot, and a local account with bypassnro.
  • GPT partitions planned first: 40 GB for Windows and the rest for Linux Mint XFCE, sharing the EFI partition.
  • Before installing Linux, I turned off Fast Startup and BitLocker in Windows.
  • Guest Additions in both systems, signed with a MOK key.

What I learned

  • Before touching the partitions, check what Windows has done on its own: version 24H2 had encrypted the disk with BitLocker without asking.
  • With Secure Boot, only signed code runs. That's why the Guest Additions compiled fine but didn't load until I enrolled the MOK key.
  • Read every installer screen: I pressed Enter instead of Continue and the keyboard stayed in English.

Oct 2026 · Personal project, still going

My home server with Proxmox

It's a computer with a Ryzen 5 2600 that works as a server at home. It hosts this site, a private cloud with Nextcloud and an ad blocker for the whole house. I haven't opened any port on the router.

  • Proxmox VE on two disks in a ZFS mirror, with snapshots and daily backups.
  • Two LXC containers: one with AdGuard Home and Tailscale for DNS and VPN, and another one with Nginx Proxy Manager.
  • Two virtual machines with Docker. One runs Nextcloud, Uptime Kuma and Homepage. The other one runs this site, kept apart from the home network by the firewall.
  • The site reaches the Internet through Cloudflare Tunnel. Internal services use HTTPS with a wildcard certificate.
  • If something goes down, I get a message on Telegram.

What I learned

  • Working when I run it by hand doesn't mean it works on its own. A backup script failed every night for weeks from cron, and I didn't notice because it threw the errors away.
  • An alert has to be tested until it arrives. I had Telegram set up, but Proxmox alerts were still going to an email nobody read.
  • The order of firewall rules matters: one rule in the wrong place left a machine without DNS or updates.
  • Changing a file doesn't change what's already running. Now I check what's really running, not what the configuration says.

May 2026 · Final project of my IT systems course, team of four

Reserfy, online table bookings for restaurants

We made up a company that sells a booking system to restaurants. We built its website and the website of an example restaurant, Échale Queso, where you can book a table. In November I restored it from a backup of the old server and put it back online on mine, fixing the parts that weren't secure.

  • Both websites are made with WordPress.
  • The booking form uses Contact Form 7 and Flamingo, and saves each booking in MariaDB. In the demo, the confirmation email is shown on screen instead of being sent.
  • A PHP plugin I wrote checks on the server the phone number, the date, that it isn't a Monday and that the booking isn't repeated.
  • Other plugins I wrote stop bots and limit bookings per IP, delete test bookings after 7 days and block XML-RPC and password attacks.
  • A Python app with Flask to view, edit, cancel and delete bookings.
  • When I restored it: fixed versions, passwords out of the code, a database user with only the permissions it needs, CSRF protection and no personal data.

What I learned

  • Coming back to a project months later is the best way to see what we did wrong: passwords in the code, unpinned versions and a database user with every permission.
  • Behind a proxy, the app has to know whether the visit came over HTTPS. WordPress got stuck in a redirect loop until I made the front nginx pass on what Cloudflare's header says.
